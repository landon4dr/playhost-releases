Host Minecraft with your friends

PlayHost sets up and runs your own Minecraft Java server on your PC, with mods, plain-language crash help, backups and easy invites. No tech skills needed.

Download for Windows

Free · Windows 10 and 11 · Updates itself

What it does

A server in about a minute

Plain Minecraft or modded (Fabric, Forge, NeoForge). PlayHost downloads Minecraft and the right Java for you.

Mods and modpacks that work

Search and install mods and modpacks. PlayHost checks they work together and fixes most problems in one click.

Crash help in plain words

If the server crashes, PlayHost tells you why ("this mod needs that mod") and offers a button that fixes it.

Invite friends easily

Friends join with one address, even if you can’t change your router settings.

Backups you can undo

Back up your world, mods and settings with one click (even while playing), and go back any time.

Commands without memorising

Search commands by what they do and fill them in with menus: give items, change the time, set game rules.

Installing

  1. Click Download for Windows and open the file.
  2. If Windows says “Windows protected your PC”, click More info, then Run anyway. PlayHost is new and not code-signed yet, so Windows doesn’t recognise it.
  3. Follow the installer, then open PlayHost and click Make my first server.

Questions

Is it free?

Yes. Everything you need to make a server, add mods and play with friends is free, with no ads.

Do I need to install Java or anything else?

No. PlayHost downloads the right Java for each Minecraft version by itself.

Does it work with Minecraft Bedrock, Mac or Linux?

Not yet: PlayHost is for Minecraft: Java Edition on Windows for now.

Does PlayHost send my data anywhere?

No. Your servers, worlds and backups stay on your PC. PlayHost has no accounts.

Does my PC need to stay on?

Yes, the server runs on your PC, so friends can join while it’s on and PlayHost is running. You can close the window and PlayHost keeps the server going from the tray by the clock.
